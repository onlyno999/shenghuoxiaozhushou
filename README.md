# 生活小助手

一些日常用的小工具页面，打开就能用，不用注册，也不用联网。

## 功能

- **单位换算**：长度（千米 / 米 / 厘米）和重量（千克 / 克 / 斤）互换
- **BMI 计算**：输入身高体重，给出 BMI 数值和参考范围
- **待办清单**：随手记事，点一下划掉，存在浏览器本地，刷新不丢

## 使用

直接用浏览器打开 `index.html` 就行，也可以把整个目录放到任意静态托管上访问。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页，三个小工具都在这一页 |
| `about.html` | 关于页 |
| `app.js` | 换算、BMI、待办的逻辑 |
| `style.css` | 页面样式 |
| `favicon.svg` | 站点图标 |
| `_worker.js` | 部署入口 |

## 小提示

待办清单的数据只存在当前浏览器的本地存储里，换设备或清缓存就没了，重要事情别只记在这儿。
